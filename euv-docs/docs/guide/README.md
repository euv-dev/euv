# Guide

The `euv-docs` build pipeline lives at `cli/README.md` frontmatter in the
`euv-dev/euv` monorepo.

## Getting started

Install `euv-cli` and run `euv-docs <SRC_DIR>` against any directory that
contains a top-level `README.md` (site config in frontmatter) plus
`*.md` content files.
