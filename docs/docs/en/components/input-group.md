A row of controls that act as one field.

## Installation

```shell
cargo add euv-ui
```

## Composition

```text
InputGroup
├── InputGroupInput
├── InputGroupAddon
├── InputGroupButton
├── InputGroupText
```

| Part             | Component                | Slot                 |
| ---------------- | ------------------------ | -------------------- |

| InputGroupButton | `euv_input_group_button` | `input-group-button` |
