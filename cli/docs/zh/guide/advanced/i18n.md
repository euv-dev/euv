# 国际化

## 语言目录

`docs/config.toml` 里每条 `[[locales]]`,只要前缀不是 `/`,都对应同名目录:

```text
docs/
├── README.md        # 英文 (prefix "/")
└── zh/
    └── README.md    # 中文 (prefix "/zh/")
```

## 语言区域

每条语言独立的 `navbar`、`footer`、`toc_label`、`prev_label`、`next_label` —— 整套 UI 都跟着翻译,不只是页面正文。

## 语言下拉

存在多个语言时,导航栏显示一个 🌐 下拉。切换语言时,如果当前页面已有翻译则保留,否则回退到该语言首页。

## 添加一门语言

1. 在 `docs/config.toml` 添加 `[[locales]]`,设 `prefix = "/fr/"`。
2. 新建 `docs/fr/README.md`。
3. 重新构建 —— 不需要其它改动。

::: warning
各语言的路由是独立的:`/guide/x.html` 与 `/zh/guide/x.html` 是两个文件构成的两页。未翻译的页面在切换语言时回退到该语言首页。
:::
